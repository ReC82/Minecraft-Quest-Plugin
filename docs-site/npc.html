PNJ

Implémentation : npc.NpcIdentityService (façade unique), npc.CitizensNpcBridge (seul point de contact avec l'API Citizens), database.NpcBindingRepository (persistance SQLite du mapping Citizens).

Deux types de PNJ pris en charge

Prioritaire PNJ Citizens

Si le plugin Citizens est installé et actif (softdepend), RPGQuest l'utilise automatiquement. L'identifiant RPGQuest est lié à NPC#getUniqueId() (UUID garanti stable par Citizens) et stocké dans data.db, table npc_citizens_bindings.

Nécessaire car Citizens recrée une nouvelle entité Bukkit à chaque (re)spawn (y compris au redémarrage) : un mapping posé sur l'entité seule serait perdu à chaque démarrage.

Non-régression Entité vanilla

Si Citizens est absent (ou pour une entité qu'il ne gère pas), l'identifiant est stocké directement dans le PersistentDataContainer de l'entité (rpgquest:npc_id) — cette entité n'est jamais recréée par un tiers, donc ça survit nativement aux redémarrages.

Dans les deux cas, le nom affiché (Entity#customName()) reste purement cosmétique : le renommer ne casse jamais le lien.

Créer un PNJ Citizens

RPGQuest ne fournit ni ne modifie aucune commande Citizens — la création et la gestion du PNJ lui-même (position, apparence, nom, squelette de comportement...) se fait entièrement avec les commandes Citizens normales, avant toute commande RPGQuest : 

# Commandes Citizens (nécessitent le plugin Citizens installé et actif),
# pas des commandes RPGQuest :
/npc create Guide          # crée un PNJ nommé "Guide" à votre position
/npc select                # sélectionne un PNJ existant à modifier
/npc remove                # supprime le PNJ sélectionné

Une fois le PNJ Citizens créé (et sélectionné, ou simplement regardé), passez à l'identification RPGQuest ci-dessous (/rpgadmin npc tag) — c'est cette étape, pas la création Citizens elle-même, qui relie le PNJ à un dialogue ou une quête.

Commande /rpgadmin npc

Permission rpgquest.admin.world. Cible toujours l'entité regardée directement, à 6 blocs maximum. Syntaxe strictement identique que le PNJ soit géré par Citizens ou non — RPGQuest détecte automatiquement lequel.

CommandeEffet
/rpgadmin npc tagIdentifie le PNJ visé avec un id auto-généré (npc_<n>).
/rpgadmin npc tag <id>Identifie le PNJ visé avec l'id choisi (minuscules, chiffres, . _ -).
/rpgadmin npc untagRetire l'identifiant (le PNJ Citizens lui-même n'est jamais supprimé).
/rpgadmin npc infoAffiche l'id actuel — pour un PNJ Citizens, ajoute (Citizens NPC #n).

tag est idempotent : sur un PNJ déjà identifié, il renvoie l'id existant sans rien changer — faites untag d'abord pour en choisir un autre.

Associer un PNJ à un dialogue/une quête

# Quête (objectif TALK_TO_NPC) — l'id doit correspondre exactement
steps:
  - id: parler_au_libraire
    objectives:
      - type: TALK_TO_NPC
        npc: libraire

# Dialogue — l'id (sans namespace) doit correspondre exactement à l'id du PNJ
# rpgquest:libraire s'ouvre automatiquement au clic sur le PNJ identifié "libraire"
id: rpgquest:libraire

Créer un PNJ de A à Z

Procédure complète, de la création du PNJ Citizens à son identification RPGQuest. Les commandes /npc ... ci-dessous sont des commandes Citizens (vérifiées sur wiki.citizensnpcs.co), pas des commandes RPGQuest — RPGQuest n'intervient qu'à partir de l'étape 5.

  1. Créer le PNJ Citizens, à votre position actuelle : 
    /npc create "Jean - le guide"
  2. Lui donner un nom — déjà fait ci-dessus en un seul passage (le nom est un argument direct de /npc create, entre guillemets s'il contient un espace). Pour renommer un PNJ déjà créé et sélectionné : 
    /npc rename "Jean - le guide"
  3. Positionner le PNJ à l'emplacement voulu : placez-vous à l'endroit exact (le PNJ créé à l'étape 1 est automatiquement sélectionné), puis : 
    /npc tphere
  4. Appliquer un skin (optionnel) — disponible directement, car /npc create crée par défaut un PNJ de type PLAYER, qui supporte les skins : 
    /npc skin <PseudoJoueur>
    RPGQuest n'a aucun rôle dans cette étape, entièrement gérée par Citizens.
  5. Attribuer un id RPGQuest stable. Regardez le PNJ directement (à 6 blocs maximum, voir la commande /rpgadmin npc ci-dessus), puis : 
    /rpgadmin npc tag jean_guide
  6. Vérifier l'association, toujours en regardant le PNJ : 
    /rpgadmin npc info
    Doit afficher jean_guide (Citizens NPC #n).
  7. Trois identifiants différents, à ne pas confondre :
    • Nom visible (Jean - le guide) — purement cosmétique, modifiable à tout moment (/npc rename) sans jamais casser le lien RPGQuest.
    • Id Citizens (ex. #7, affiché entre parenthèses par /rpgadmin npc info) — numérique, attribué par Citizens, non garanti stable dans le temps : jamais utilisé par RPGQuest comme clé de persistance.
    • Id RPGQuest (jean_guide) — celui attribué par /rpgadmin npc tag, le seul utilisé dans les fichiers de quête/dialogue (npc: jean_guide, id: rpgquest:jean_guide).
  8. Déplacer le PNJ plus tard (après cette procédure initiale) : resélectionnez-le avec Citizens, puis retéléportez-le comme à l'étape 3 : 
    /npc select jean_guide   # ou /npc select <id numérique Citizens>
/npc tphere
    L'id RPGQuest n'est pas affecté par un déplacement : il est lié à NPC#getUniqueId(), jamais à la position.
  9. Retirer uniquement le tag RPGQuest (le PNJ Citizens lui-même reste en place) : en regardant le PNJ : 
    /rpgadmin npc untag
  10. Supprimer complètement le PNJ Citizens (irréversible côté Citizens) : faites l'étape précédente d'abord si un id RPGQuest est encore associé (voir « Limites connues » ci-dessous) : 
    /npc select jean_guide
/npc remove

Exemple : Jean - le guide

Séquence complète, dans l'ordre, copiable directement dans Minecraft (adaptez le pseudo du skin) : 

# 1-2. Créer le PNJ avec son nom
/npc create "Jean - le guide"

# 3. Se placer à l'emplacement voulu, puis déplacer le PNJ (déjà sélectionné) dessus
/npc tphere

# 4. Skin (optionnel)
/npc skin Notch

# 5. Regarder le PNJ, puis lui attribuer un id RPGQuest stable
/rpgadmin npc tag jean_guide

# 6. Vérifier l'association (toujours en regardant le PNJ)
/rpgadmin npc info
# -> jean_guide (Citizens NPC #n)

À partir de là, jean_guide peut être référencé dans un fichier de quête (npc: jean_guide) ou de dialogue (id: rpgquest:jean_guide) — voir Dialogues et Quêtes.

Limites connues

  • Aucune liste globale des PNJ identifiés — il faut viser physiquement l'entité.
  • Supprimer un PNJ Citizens (/npc remove) ne nettoie pas automatiquement le mapping RPGQuest — faites /rpgadmin npc untag avant.
  • Aucune protection/persistance automatique du PNJ lui-même en dehors d'une zone protégée (pas d'invulnérabilité ni de respawn intrinsèque) — RPGQuest ne gère que l'identité, pas le cycle de vie de l'entité. À l'intérieur d'une zone protégée (voir Spawn du village), un PNJ Citizens est en revanche protégé de tout dégât par défaut (flag npc-damage).
